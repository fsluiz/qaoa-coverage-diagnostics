# Archived results

These JSON files are evidence for the article calculations. They are kept under
version control because several runs require hours or remote quantum hardware.

`rydberg_3x3_exact.json` and the two `ilp_geographic_ibge_2024_*.json` files are
the corrected August 2026 results. Do not use the superseded sampled Rydberg or
synthetic geographic values from older Git history. Remaining limitations are
documented in `../AUDIT.md`.
